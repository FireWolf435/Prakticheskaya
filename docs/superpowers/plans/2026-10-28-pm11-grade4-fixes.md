# ПМ.11: исправления для оценки 4 — план

> Цель: довести проект до воспроизводимого состояния по требованиям ПМ.11 на оценку 4.

## Блоки

1. **RLS:** добавить реальные политики в init SQL, проверить сотрудника/инженера/руководителя и ограничение `FORCE ROW LEVEL SECURITY`.
2. **pgcrypto:** добавить encrypted-поля для СНИЛС и даты рождения, функции доступа через ключ из окружения, не хранить ключ в БД.
3. **Минимальные программные сервисы:** добавить FastAPI API, notifier worker и `ops/` backup/restore scripts; не создавать лишнюю бизнес-логику.
4. **LDAP:** сделать полный воспроизводимый LDIF import при чистом запуске, проверить `dirsync` по `employeeNumber`, блокировку уволенных.
5. **Данные:** восстановить рабочий набор в новом Docker volume и проверить контрольные количества.
6. **Тесты:** исправить импорты/подключения, запускать pytest после поднятия PostgreSQL, убрать ложные тестовые утверждения.
7. **Проверка:** выполнить pg_dump/restore в отдельной тестовой БД, проверить RLS/pgcrypto/API/LDAP и зафиксировать результаты.

## Ограничения

- Не затрагивать ПМ.02 сверх пересечения с ПМ.11.
- Не добавлять фиктивные подтверждения: документация не заменяет работающий код.
- Секреты не коммитить.
- UML/IDEF0/DFD не реализовывать: их рисует пользователь.
