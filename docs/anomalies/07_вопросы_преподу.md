# Аномальные случаи ВНЕ явного описания ТЗ — вопросы преподавателю

**Назначение:** дефекты данных, найденные при анализе (пункт 3.2), которые **не описаны прямым
текстом в индивидуальном задании**. По каждому — что найдено, сколько записей и готовый вопрос.

**Что задание называет ПРЯМО** (раздел 3, примечание):
> «Нельзя доверять **кодировкам, форматам дат, уникальности, часовым поясам и ссылкам между файлами**».

Плюс отдельные требования ТЗ: СНИЛС с контрольной суммой (4.1), маскирование паролей и логинов
из легаси-заявок (4.3.5), непересечение смен дежурств (разд. 1 п. 6), автоответы и петля писем
(5.1, 5.3). Эти аномалии считаю «в задании» — вопросов нет (кратко в разделе A).

**Всё остальное → спорно** и вынесено в раздел B с вопросами.

## C. Проверено, но НЕ найдено (0 записей) — сверить с эталоном

Возможно, преподаватель ожидал эти аномалии — тогда стоит уточнить.

- Дубли табельных номеров — 0
- Дубли инвентарных номеров (кроме служебной строки) — 0
- Дубли `uid` и `mail` в LDAP — 0
- Дубли дат в производственном календаре — 0
- Дубли навыков «табельный + категория» — 0
- Пустые обязательные поля (ФИО, табельный, СНИЛС) — 0
- Увольнение раньше приёма — 0
- Дата приёма/увольнения/рождения в будущем — 0
- Возраст старше 100 лет — 0
- Подразделение «сам себе родитель» — 0
- Битые ссылки заявка↔автор↔исполнитель — 0
- Заявки без истории статусов — 0
- Событие истории раньше создания заявки — 0
- Даты в будущем в перемещениях CMDB — 0
