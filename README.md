# Service Desk — система учёта и обработки заявок технической поддержки

Информационная система технической поддержки (Service Desk) для ООО «Вектор-Пром»:
приём и обработка заявок, учёт оборудования, каталог пользователей (LDAP) и
почтовая интеграция.

Проект выполняется в рамках двух производственных практик:

- **ПМ.11** «Разработка, администрирование и защита баз данных» — ядро: БД,
  её администрирование и защита
- **ПМ.02** «Осуществление интеграции программных модулей» — программные модули
  на Python вокруг ядра, их интеграция и тестирование

## Инструменты

| Технология | Назначение |
|---|---|
| PostgreSQL 16+ | данные, бизнес-правила, безопасность |
| Python 3.12+ | доменная логика, модули интеграции |
| Docker Compose | развёртывание всего стенда одной командой |
| OpenLDAP | централизованный каталог пользователей |
| docker-mailserver | почтовый сервер  |

## Архитектура

| Компонент | Назначение |
|---|---|
| `postgres` | PostgreSQL 16+ данные бизнес-правила безопасность |
| `ldap` | OpenLDAP  каталог пользователей локальной сети |
| `mail` | docker-mailserver аутентификация через LDAP |
| `core` | доменная логика  |
| `api` | REST API на FastAPI контракт в OpenAPI |
| `notifier` | воркер: читает outbox через `LISTEN/NOTIFY` шлёт письма по SMTP |
| `mailintake` | забирает письма по IMAP, создаёт заявки/комментарии |
| `dirsync` | синхронизирует LDAP с БД и ролями PostgreSQL |
| `importer` | загрузка исходных данных: staging > очистка > целевые таблицы |
| `desk-client` | десктоп-клиент на PySide6  |
| `ops/` | скрипты резервного копирования восстановления |

## Работа с исходными данными 

Данные выдаются архивом. Данные намеренно не очищены —
поиск и устранение аномалий являются частью задания.
