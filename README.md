# Service Desk — ПМ.11 «Разработка, администрирование и защита баз данных»

Производственная практика. Разработка защищённой информационной системы учёта и обработки заявок технической поддержки (Service Desk) с централизованным каталогом пользователей и почтовой интеграцией.

## Стек

- PostgreSQL 16+
- Docker Compose
- Python 3.12+ (для модулей core, api, importer, dirsync, mailintake, notifier)
- OpenLDAP, docker-mailserver

## Структура репозитория

```
service-desk-pm11/
├── .env.example              # шаблон переменных окружения (скопировать в .env)
├── .gitignore                # игнорируемые файлы (секреты, кэш, логи)
├── docker-compose.yml        # поднимает postgres, ldap, mail одной командой
├── README.md                 # этот файл
│
├── db/
│   └── init/                 # SQL-скрипты инициализации базы (выполняются при старте postgres)
│       ├── 01_schemas.sql           # схемы ref, core, audit, sec, stage
│       ├── 02_domains.sql           # домены email, snils, inv_no, phone, birth_date, status, priority
│       ├── 03_tables_ref.sql        # справочники (отделы, категории, SLA, календарь, навыки, дежурства)
│       ├── 04_tables_core.sql       # предметная область (сотрудники, заявки, оборудование, outbox)
│       ├── 05_tables_audit.sql      # аудит (log секционировано по месяцам, security_events, ddl_log)
│       ├── 06_tables_sec.sql        # безопасность (пользователи, роли, сессии, история паролей)
│       └── 07_tables_stage.sql      # staging-таблицы для загрузки исходных данных «как есть»
│
├── importer/                 # модуль загрузки исходных данных (staging → целевые таблицы)
├── dirsync/                  # синхронизация LDAP с БД и создания ролей PostgreSQL
├── mailintake/               # обработка входящей почты (IMAP → заявки/комментарии)
├── notifier/                 # фоновый воркер уведомлений (outbox → SMTP)
├── core/                     # доменная логика (Python-пакет)
├── api/                      # REST API на FastAPI (OpenAPI)
├── ops/                      # скрипты резервного копирования, восстановления, мониторинга
├── ldap/                     # LDIF-файлы для OpenLDAP
├── mail/                     # конфигурация docker-mailserver
├── docs/                     # документация (ER-модель, отчёт по ПМ.11 и т.д.)
└── diary/                    # дневник практики
```

## Требования к БД (ПМ.11)

- 18+ таблиц в схемах `ref`, `core`, `audit`, `sec`, `stage`
- Домены: `email` (citext), `snils` (с контролльной суммой), `inv_no`
- EXCLUDE USING gist по tstzrange для графика дежурств (границы `[)`)
- Частичный уникальный индекс: один СНИЛС — один действующий трудовой период
- 7+ функций и процедур: `calc_sla_deadline`, `calc_sla_spent`, `change_ticket_status`, `auto_assign`, `reopen_ticket`, `move_asset`, `sec.register_user`, отчётная табличная функция
- 6+ триггеров: аудит, запрет переходов статусов, пауза SLA, outbox + pg_notify, updated_at/версия, event trigger DDL
- 12+ запросов: оконные функции, WITH RECURSIVE, LATERAL/FILTER/GROUPING SETS/ROLLUP, полнотекстовый поиск
- RLS, pgcrypto, 3 docker-сети, pg_hba.conf, SSL, клиентский сертификат для dba

## Первичная настройка (после установки Docker)

```bash
# 1. Скопировать пример переменных окружения
cp .env.example .env
# 2. Заполнить .env своими паролями (не коммитить в git!)
# 3. Поднять базу данных
docker compose up -d
```
